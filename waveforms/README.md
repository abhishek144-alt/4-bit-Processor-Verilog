# Waveform Screenshots

This directory contains the simulation waveform screenshots for the 4-bit processor:

```text
waveforms/
├── alu_waveform.png
├── register_file_waveform.png
├── control_unit_waveform.png
├── program_counter_waveform.png
├── instruction_memory_waveform.png
├── data_memory_waveform.png
├── processor_waveform.png
└── test_result.png
```

### Module Waveform Descriptions:
1. **`alu_waveform.png`**: Simulation of Arithmetic Logic Unit operations (ADD, SUB, AND, OR, XOR, NOT, etc.).
2. **`register_file_waveform.png`**: Read and write operations across general-purpose registers.
3. **`control_unit_waveform.png`**: Control signals generated based on instruction opcodes.
4. **`program_counter_waveform.png`**: Program counter increment, reset, and branch updates.
5. **`instruction_memory_waveform.png`**: Instruction fetch cycles corresponding to PC addresses.
6. **`data_memory_waveform.png`**: Memory read/write waveforms (RAM operations).
7. **`processor_waveform.png`**: End-to-end integrated processor execution waveform showing instruction execution flow.
8. **`test_result.png`**: Simulation test bench console verification output showing expected vs. actual results.
